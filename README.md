# WinVerse™ Homepage

Static, responsive company homepage for WinVerse™ and the investigational SerotoniX™ facial neuromodulation research platform.

## Safety and evidence boundary

- Investigational technology only; no treatment or efficacy claims.
- The website distinguishes early published evidence from the ongoing controlled evidence pathway.
- UHN/KITE is identified as the research origin without implying endorsement, ownership by WinVerse, or regulatory approval.
- Any WinVerse technology rights are described as subject to definitive agreements.

## Local preview

Open `index.html` directly, or serve the directory with any static HTTP server.

## GitHub Pages

The included workflow publishes the repository root to GitHub Pages. In repository settings, choose **Pages → Source → GitHub Actions** if it is not already selected.
